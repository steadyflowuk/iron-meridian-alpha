# Iron Meridian: alpha

A real-time grand strategy game: lead one of 64 nations against the world (single player against bots in this alpha).

**Play:** https://steadyflowuk.github.io/iron-meridian-alpha/

## Install it as an app
- **iPhone / iPad:** open the link in **Safari**, tap **Share**, then **Add to Home Screen**.
- **Android:** open the link in Chrome and tap **Install** on the home screen (or Install app in the menu).
- **Windows / Mac:** open the link in Chrome or Edge and tap **Install** on the home screen or the install icon in the address bar.

Once installed it runs full screen, works offline and updates itself (an "Update now" bar appears when a new version is ready).

## Report a bug
In the game: **Report a bug** (home screen, or More in a campaign). Download the report, then open a [new issue](https://github.com/steadyflowuk/iron-meridian-alpha/issues/new) and attach the file. A free GitHub account is needed to post; otherwise send the file to the developer.

This repository holds only the built game. Source code is private.
